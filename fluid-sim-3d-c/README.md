# fluid-sim-3d-c

C23, OpenMP, OpenGL 4.6 compute로 만든 유체·재료 물리 샌드박스다. 편집용 높이장, 3D FLIP 입자, 고품질 연속 수면, 탄성체·점토·과립체가 충돌하는 GPU MPM 재료 실험실의 네 모드를 제공한다. 각 모드의 구현·난이도·특이사항은 [docs/MODES.md](docs/MODES.md), 모듈과 데이터 흐름은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 최종 sparse FLIP·whitewater·오프라인 렌더링 목표는 [docs/CINEMATIC_TARGET.md](docs/CINEMATIC_TARGET.md)에서 관리한다.

## 실행

```sh
make run
```

루트 `make check`는 이 프로젝트의 포커스 손실 시 키 해제, 마우스 capture 취소와 드래그 release 이벤트를 검사한다. 창 전환 뒤 카메라 이동이나 물체 드래그가 붙지 않도록 입력을 정리한다. GPU 물리의 수치 정확도나 네 모드의 화질을 자동 판정하는 테스트는 아니다. 범위는 [공통 테스트](../tests/README.md)에 있다.

## 실행 모드

네 모드의 물리 모델, 구현 구조, 난이도, 성능과 한계에 대한 상세 비교는 [모드 카탈로그](docs/MODES.md)를 참고한다.

- 기본 `Preview`: `256×256` 높이장과 물체 팔레트를 60 FPS로 편집한다.
- `G` - `Realtime FLIP particles`: 126,300개 입자, `48×32×48` 격자와 36회 압력 반복을 사용하며 입자를 직접 표시한다. `G`를 다시 누르면 `Preview`로 돌아간다.
- `H` - `High Quality Surface`: 834,104개 입자, `88×58×88` 격자와 80회 압력 반복을 사용한다. 깊이·두께 입자 패스, 양방향 깊이 블러와 연속 수면 합성, Fresnel 환경 반사, 실제 장면 굴절, Beer-Lambert 흡수, 태양광 반사와 구조물 그림자를 적용한다. `H`를 다시 누르면 `Preview`로 돌아간다.
- `M` - `MPM Material Lab`: 301,011개 입자와 `80×72×68` 공유 격자에서 탄성체, 점토성 소성체와 과립체를 APIC/MLS-MPM으로 계산한다. 서로 반대 방향으로 회전하는 충돌체가 세 재료를 압축·늘림·항복·흩뜨린다. `M`을 다시 누르면 `Preview`로 돌아간다.

`H`는 처음 누를 때 고해상도 버퍼와 셰이더를 준비하므로 잠시 멈출 수 있다. RTX 3060 Ti의 1440×900 측정값은 약 25~26 FPS, GPU 사용률 99%다. 화면 공간 수면은 실시간 고품질 모드이며, 참조 논문의 오프라인 SDF 메시와 path tracing 결과를 그대로 대체하는 최종 `Cinematic Bake`는 아니다.

`M`도 처음 누를 때 입자와 격자 버퍼를 지연 생성한다. 같은 장비와 해상도의 과거 정상 상태 관찰값은 약 55~60 FPS, GPU 사용률 약 92%다. 과거 기록의 GPU 메모리 약 483 MiB는 프로세스별 계측 방법이 남아 있지 않으므로 앱 전용 VRAM 사용량으로 확정하지 않는다. 이번 유지보수에서 해당 성능값을 재측정한 것은 아니다.

화면 오른쪽 위 HUD는 현재 모드, 사용 중인 시뮬레이션과 입자 표현을 항상 표시한다. 마지막 줄에는 현재 상태에서 `G`, `H`, `M`을 눌렀을 때 전환되는 모드가 표시되므로 README를 열지 않고도 모드를 바꿀 수 있다.

## 물체 팔레트

물체 팔레트는 `Preview` 모드에서 사용한다. 화면 왼쪽 팔레트의 물체를 클릭한 채 수면으로 끌고 가서 놓는다. 숫자키로 종류만 선택한 뒤 팔레트에서 끌 수도 있다.

1. 목재 상자: 부력, 수면 항력, 파도 경사에 따른 흔들림과 회전
2. 모래성: 물에 잠긴 시간과 유속에 따른 침식, 결합력 감소와 붕괴
3. 천: 질점과 구조·전단 제약, 중력, 부력, 수면 항력에 따른 변형
4. 유리벽: 낮은 충격 한계의 연결 조각, 충격과 낙하에 따른 파손·침강
5. 레고 탑: 개별 블록, 파괴 가능한 수직·수평 연결, 충돌과 부유
6. 뗏목: 여러 목재 판재의 파괴 가능한 연결, 파도에 따른 휨과 분리

배치된 물체를 왼쪽 클릭해서 다시 끌 수 있다. 선택된 구조물은 밝게 표시되며 `Delete` 또는 `Backspace`로 그룹 전체를 지운다. `R`은 물과 모든 물체를 초기화한다.

## 카메라와 파도

- `WASD`: 수평 이동
- 마우스 오른쪽 드래그 또는 방향키: 시점 회전
- 마우스 휠: 줌 인 / 줌 아웃
- `Space` / `C`: 상승 / 하강
- `Shift`: 빠르게 이동
- `G`: 실시간 FLIP 입자 모드 전환
- `H`: 고품질 연속 수면 모드 전환
- `M`: MPM 재료 실험실 모드 전환
- 빈 수면 왼쪽 드래그: 현재 FLIP/높이장 물을 밀어 파동 생성
- MPM 재료 위 왼쪽 드래그: 국소 외력을 가해 재료를 들어 올리고 흩뜨림
- `F`: 물 모드에서는 큰 충돌 파도, MPM 모드에서는 중앙 하강 충격 발생
- `R`: 현재 물과 모든 모드의 시뮬레이션 초기화
- `Esc`: 종료

## 구현 구조

- `main.c`: 앱 수명, 입력 조정, 고정 시간 간격 루프
- `src/fluid_sim.c`: 유체, 포말, 비산 물방울과 위치별 수면 샘플링
- `src/physics_world.c`: 강체, 부력, 항력, 충돌, 파괴 연결, 침식, 천 제약
- `src/renderer.c`: 하늘·바닥·물 렌더링 패스 조정
- `src/gpu_fluid.c`: 품질 프로필별 3D FLIP/PIC 입자·격자 시뮬레이션
- `src/gpu_surface.c`: 입자 깊이·두께, 블러, 굴절·반사 수면 합성
- `src/gpu_mpm.c`: MPM 입자·격자 실행, 초기 재료 장면, 충격과 드래그 외력
- `src/hud_renderer.c`: 현재 모드·시뮬레이션과 전환 키 HUD
- `src/object_renderer.c`: 고체·유리·천·배치 미리보기·팔레트 렌더링
- `src/gl_api.c`: OpenGL 함수 로딩과 외부 GLSL 컴파일
- `src/platform.c`: Win32 입력, OpenGL 4.x 코어 컨텍스트, VSync
- `src/camera.c`: 자유 카메라, 화면 레이와 수면 투영
- `shaders/flip_*.comp`: FLIP 유체 P2G, 압력 투영과 G2P
- `shaders/mpm_*.comp`: MPM 재료 P2G, 격자 충돌과 G2P/APIC
- `shaders/`: 물, 재료 입자, 바닥, 하늘, 물보라, 물체와 UI GLSL

유체는 OpenMP로 CPU 코어에 분산하여 120 Hz로 계산하고 렌더링은 두 물리 상태 사이를 보간한다. 물체는 수면 높이와 유속을 샘플링해 부력·항력·회전력을 받고, 반작용을 다시 수면 파동으로 전달한다.

`Preview` 물은 넓은 수면에 적합한 높이장 모델이고, `G`와 `H`는 물체 주변을 흐르고 공중에서 분리되는 3D FLIP 입자를 계산한다. `M`은 유체 압력 해석 대신 변형 구배와 재료별 탄성·항복 투영을 계산하므로 고무, 점토와 모래 같은 고체·반고체 거동을 보여준다. `H`의 연속 수면은 화면 공간 재구성이므로 카메라에서 보이는 결과에 최적화되어 있다. 오버행을 완전한 메시로 저장하거나 기포·얇은 물막까지 보존하는 오프라인급 결과는 SDF/anisotropic surface, whitewater와 프레임 캐시가 추가되어야 한다.
